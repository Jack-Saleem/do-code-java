STATIC IMPORT:
Static imports allows to bring the static variables, methods & constants from a class.
When a source file having Ststic members in the current class, Explicit import statment & Implicit import statment then the priority goes like

Current_class Static members
			|
			|
			- - > Explicit Static import
							|
							|
							- - > Implicit Static import
							
Syntax for Explicit Static import:
import static package_name.class_name.static_members;
ex:
import static java.lang.math.sqrt;
import static java.lang.system.out;

Syntax for Implicit Static import:
import static package_name.class_name.*;
ex:
import static java.lang.math.*;
import static java.lang.system.*;

Reasons to avoid this static import in programming practice:
Two packages having a class or interface with same name is very rare hence, ambiguity issue is also very rare.
Two classes or interfaces having variables or methods with same name are very common then, ambiguity issue is very common problem with static import.
Usuage of this static import reduces the readability, maintainablity and creates confusions hence, if there is no specific reason it's not recomended to use this static import.

DIFFERENCE BETWEEN NORMAL IMPORT AND STATIC IMPORT:
NORMAL IMPORT:
1. We use normal import to import classes & interfaces of a particular package.
2. When we are using import statments it's not required to use fully qualified name, we can use short names directly.

STATIC IMPORT:
1. We can use static import to import the static members of the particular class or interface.
2.When we use static import it's not required to use class name to access static members, we can access them directly.
