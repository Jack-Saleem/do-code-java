Data Hiding

Definition:

It's all about to maintain the privacy & security of the data, who can access, the data is be accessible by the verified persons who are authenticated.
No outside person is allowed to access the data.
By declaring a data members(Variables) with private access modifier we can achive this Data Hiding.
example:
public class Test
{
private int value;
public int getValue()
{
//validation return value;
} }
Advantages:
Security.
