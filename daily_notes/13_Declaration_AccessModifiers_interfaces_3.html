Marker Classes:

Definition: If an interface dosen't contains any methods in it and by implementing that interface if the object posses some kind of abilities then such type of interfaces or called to e as marked interfaces

Ex:
Serializable (I)
Clonable (I)
RandomAccess (I)
SingleThreadModel (I)

Adapter Classes

Definition: A simple java class that implements an interface with only empty implementations.
If we implement interface method out of 1000 methods the we need to implement the method that we want to implement and also implement the other methods also as empty,
which will takes alot of time, instead of this we just use an Adapter class to do the empty methods implementation and we just extends that class.
