SOURCE FILE STRUCTURE:
A java file can contain any no. of classes.
As long as the source file is not having any public class in it there's no need to specify the file & class name with the same name.
If the file have public class in it then the file name definetly needs to be class name.
A java file can have atmost one public class.

We can compile a java source file i.e., test javac compiles the whole java file
When we run test java then the main method inside the file will be execuited.
If there is no main method then a run time exception will araise. 
Recomended to take only one class per source file.

IMPORT STATMENTS:
Import statment helps in improving the readbility of the code, without this import statment we need to use 'fully qualified name' everytime we go through that class.
With this import statment we can directly use the short name.

ex:
import java.util.ArrayList;
public class Test {
	public static void main(String[] args) {
		ArrayList I = new ArrayList();
	}
}
 
 Hence, we can say that import statment works as the typing shortcut for fully qualified name.
