Differences between Interface and Abstract Classes.

Interface Abstract Class
1. If we don't know anything abt the implementation and we just have the required specifications, then we should go for INTERFACES 1. If we are talking abt the implementation but not completly then we should go for Abstract Classes
2. Inside Interface every method is by default public and abstract whether we declare them or not so, Interface is comsidered to be as 100% pure abstract class 2. Every method inside the abstract class need not to be as public and abstract.
3.As every method in interface is always public & abstract we can't declare them with with
private, protected, final, static, native, synchronized, strict fp 		3. We can declare a method with those access modifiers, there's no restrictions in abstract class.
4. Variables in Interface are always set on public, static, final no matter we declare or not. 4. Here variable are not set by default like that, there's no such restrictions.
5. Declaring variables with access modifiers like private, protected, transient, volatile is not allowed, the variable always fixed with public, static, final. 5. Here we can declare the variable with any of those access modifier according to our requirment.
6. For interface variables initialization should be performed during the time of initialization, otherwise we'll get (C.E). 6. It's not mandatory to initialize the variables during the declaration.
7. Inside interface we can't declare static or instance blocks. 7. possible to declare static and instance blocks.
8. It's not possible to declare a Constructor inside an interface. 8. It is possible to declare a Constructor inside a abstract class.
