Encapsulation (Data Members + Methods)


Definition:
THe process of binding the data & the corresponding methods into a single unit is nothing but Encapsulation.
If a component follows both the Data Hiding and the Abstraction mechanisms then it is said to be the encapsulated component.

Encapsulation = Data Hiding + Abstraction


Example:
public class Account
{
public double balance;
publuc double getBalance()
{
// validation
return balance;
}
public double setBalance(double balance)
{
//validation
this.balance = balance;
    }
}

Advantages: 
1. Security is mainly one of the main advantage.
2. Enhancement becomes easy.
3. Improves the maintainablity of the application.
        The main advantagge of this is security but it increases the execuition time and and also increases the length of the code.


Tightly Encapsulated Class

A class is said to be a tightly ena=capsulated class if every data member inside it is declared as private whether getter and setter methods are declared or not & class is declared as public or not,
These things are not required to check.

Example:

    public class Account 
    {
        private double balance;
        public double getBalance()
        {
            return balance;
        }
    }

Note: If the parent class is not tightly encapsulated then no corresponding child class will be tightly encapsulated.
