Interfaces Vid - 1

Introduction:

Definition:

Any Service Requirment Specification (or)
Any contract between client and service provider (or)
A pure abstract class is nothing but an INTERFACE.

Declaration & Implementation:

For every method that we declare in interface needs to be implemented in the class otherwise we should declare that class as abstractso, that the next child class will implement those methods.
Every interface method is by default public and abstract, dosen't matter whether we declare them with them or not. so, whenever we're implementing that interface method then it's mandatory to declare that method as public or else we'll get compile time error.

Extends VS Implements:

1. A class can extend only one class at a time, but an interface can extend any no. of interfaces simultaneously.

Example:
interface A
{
}
interface B
{
}
interface C extends A, B
{
}

2. A class can implement any no. of interfaces.
A class can extend and can implement any no. of interfaces.

Example
class A extends B Implements C,D,E
{
}
